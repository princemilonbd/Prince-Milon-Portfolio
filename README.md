# Prince Milon — Musician Website

A responsive personal musician portfolio designed for GitHub Pages.

## Files
- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — mobile menu and demo music buttons

## GitHub Pages
1. Create a GitHub repository (for example: `prince-milon`).
2. Upload all three files to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide your live website address.

## Customize
Replace the demo songs, dates, social links, biography, stats and text with your real information. Add Spotify/YouTube links to the music buttons.
